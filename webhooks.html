Webhooks

Webhooks notify your server about payment events in real-time. They're the most reliable way to know when a payment succeeds or fails.

Why Use Webhooks?​

  • Reliable: Don't depend on customers returning to your site
  • Real-time: Get notified immediately when payments complete
  • Secure: Verify authenticity with signatures
  • Async: Process payments without blocking your checkout flow

Setting Up Webhooks​

  1. Go to Dashboard → Settings → Webhooks
  2. Enter your webhook URL (must be HTTPS in production)
  3. Select events to subscribe to
  4. Copy the webhook secret for signature verification

Signature Verification​

Always verify webhook signatures to ensure authenticity. Webhooks include a signature header: X-P4W-Signature

  • Node.js
  • Python
  • PHP
  • Ruby
  • Go
const crypto = require('crypto');

function verifyWebhookSignature(payload, signature, secret) {
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(JSON.stringify(payload))
    .digest('hex');

  // Use timing-safe comparison to prevent timing attacks
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  );
}

// Express.js middleware
app.post('/webhooks/pay4work', express.json(), (req, res) => {
  const signature = req.headers['x-p4w-signature'];

  if (!verifyWebhookSignature(req.body, signature, process.env.WEBHOOK_SECRET)) {
    console.error('Invalid webhook signature');
    return res.status(401).send('Invalid signature');
  }

  // Process the webhook
  const { event, data } = req.body;

  switch (event) {
    case 'payment.success':
      handlePaymentSuccess(data);
      break;
    case 'payment.failed':
      handlePaymentFailed(data);
      break;
    // ... handle other events
  }

  // Always return 200 to acknowledge receipt
  res.status(200).send('OK');
});
import hmac
import hashlib
import json
from flask import Flask, request

app = Flask(__name__)

def verify_webhook_signature(payload, signature, secret):
    expected = hmac.new(
        secret.encode(),
        json.dumps(payload, separators=(',', ':')).encode(),
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(signature, expected)

@app.route('/webhooks/pay4work', methods=['POST'])
def handle_webhook():
    signature = request.headers.get('X-P4W-Signature')

    if not verify_webhook_signature(request.json, signature, WEBHOOK_SECRET):
        return 'Invalid signature', 401

    event = request.json.get('event')
    data = request.json.get('data')

    if event == 'payment.success':
        handle_payment_success(data)
    elif event == 'payment.failed':
        handle_payment_failed(data)

    return 'OK', 200

package main

import (
    "crypto/hmac"
    "crypto/sha256"
    "encoding/hex"
    "encoding/json"
    "net/http"
)

func verifyWebhookSignature(payload []byte, signature, secret string) bool {
    mac := hmac.New(sha256.New, []byte(secret))
    mac.Write(payload)
    expected := hex.EncodeToString(mac.Sum(nil))
    return hmac.Equal([]byte(signature), []byte(expected))
}

func webhookHandler(w http.ResponseWriter, r *http.Request) {
    signature := r.Header.Get("X-P4W-Signature")

    var payload map[string]interface{}
    json.NewDecoder(r.Body).Decode(&payload)

    payloadBytes, _ := json.Marshal(payload)

    if !verifyWebhookSignature(payloadBytes, signature, webhookSecret) {
        http.Error(w, "Invalid signature", http.StatusUnauthorized)
        return
    }

    event := payload["event"].(string)
    data := payload["data"].(map[string]interface{})

    switch event {
    case "payment.success":
        handlePaymentSuccess(data)
    case "payment.failed":
        handlePaymentFailed(data)
    }

    w.WriteHeader(http.StatusOK)
    w.Write([]byte("OK"))
}

Retry Policy​

If your endpoint doesn't respond with HTTP 2xx within 30 seconds, we will retry:

AttemptDelay
1st retry5 minutes
2nd retry30 minutes
3rd retry2 hours
4th retry8 hours
5th retry24 hours

After 5 failed attempts, the webhook is marked as failed. You can view failed webhooks and trigger manual retries from the dashboard.

Best Practices​

1. Respond Quickly​

Return a 200 response as soon as possible. Process the webhook asynchronously:

app.post('/webhooks/pay4work', (req, res) => {
  // Immediately acknowledge receipt
  res.status(200).send('OK');

  // Process asynchronously
  processWebhook(req.body).catch(console.error);
});

async function processWebhook(payload) {
  // Do your actual processing here
  const { event, data } = payload;

  if (event === 'payment.success') {
    await updateOrderStatus(data.orderId, 'paid');
    await sendConfirmationEmail(data.customer.email);
    await fulfillOrder(data.orderId);
  }
}

2. Handle Idempotency​

Webhooks may be delivered more than once. Use the event id to deduplicate:

const processedEvents = new Set(); // Use Redis in production

async function processWebhook(payload) {
  if (processedEvents.has(payload.id)) {
    console.log('Duplicate webhook, skipping:', payload.id);
    return;
  }

  processedEvents.add(payload.id);
  // Process the event...
}

3. Always Verify Signatures​

Never trust webhook data without verifying the signature. This prevents attackers from spoofing webhooks.

4. Use HTTPS​

Your webhook endpoint must use HTTPS in production. This ensures the webhook data is encrypted in transit.

5. Log Everything​

Keep detailed logs of webhook events for debugging:

app.post('/webhooks/pay4work', (req, res) => {
  console.log('Webhook received:', {
    id: req.body.id,
    event: req.body.event,
    timestamp: req.body.timestamp,
  });

  // Process webhook...

  res.status(200).send('OK');
});

6. Handle All Events​

Always have a default case for unknown events:

switch (event) {
  case 'payment.success':
    // ...
    break;
  case 'payment.failed':
    // ...
    break;
  default:
    console.log('Unknown event type:', event);
}

Webhook Endpoint Requirements​

  • Must accept POST requests
  • Must return HTTP 2xx within 30 seconds
  • Must accept application/json content type
  • Should use HTTPS (required in production)
  • Should verify signatures

Troubleshooting​

Webhooks Not Arriving​

  1. Check your webhook URL is correct in dashboard
  2. Verify your server is publicly accessible
  3. Check firewall/security group settings
  4. Look at webhook delivery logs in dashboard

Signature Verification Failing​

  1. Ensure you're using the correct webhook secret
  2. Verify you're comparing the raw request body (not parsed JSON)
  3. Check for whitespace or encoding issues

Duplicate Webhooks​

This is normal behavior for retries. Implement idempotency handling using the event id.
